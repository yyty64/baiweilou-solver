# 百味楼配队

《爆炒江湖》百味楼的网页配队工具。导入自己的厨师档案、填写本层点单和上阵人数上限，即可搜索厨师与站位组合，并查看每道菜的技法、品级、加成和分数。

[打开百味楼配队网页](https://yyty64.github.io/baiweilou-solver/)

## 使用方法

1. 在游戏中进入「头像 → 设置 → 白菜菊花」，复制校验码，粘贴到网页的「我的档案」并导入。也可以导入 L 图鉴导出的个人备份文件。
2. 填写本层目标分数和上阵人数上限。默认上限为 3 人，可按关卡调整。
3. 按菜名添加本层点单。图鉴会填入口味、技法、火数和食材，并按个人档案中的专精状态填入售价。可逐道勾选或取消「已专精」来切换售价，也可手动填写活动售价。
4. 点击「计算阵容」。默认在找到过线方案后停止，也可选择「找更高分」。达到搜索时限时，页面会显示当前找到的最好结果。可在「计分参数」中选择「完整遍历」来取消时限。

## 调整厨具

- 取消勾选「使用厨具」后，求解器按各厨师在档案中已绑定的厨具计算。
- 勾选「使用厨具」后，求解器按本层点单从全图鉴自动试配。每种厨具至少模拟一件，档案记录多件时沿用该件数。可以在「固定个别厨师的厨具」里指定厨具，留空可让该厨师空装备上阵。
- 两种方式均计入厨师已装备的遗玉。
- 搜索空间较大时，求解器优先给较高分的候选阵容试配厨具，页面会标明结果是搜索到的较优搭配。
- 自动搭配出结果后，可直接修改上阵厨师的厨具，再点「重算营业金额」。网页按原厨师和站位复算本层点单，并显示与修改前的分差。换装只用于网页模拟。

## 计分说明

- 按网页选定的厨具和个人档案中的遗玉、修炼状态计算。具有「下一位」效果的厨师会按上阵顺序判断效果。
- 双技法菜按两项技法的达标倍数中较低的一项定品级。任一项达不到基础要求时，该菜计 0 分。
- 先应用基础售价加成，再计算普通售价、金币和品级加成。各菜分数合计后四舍五入。
- 默认分数必须超过目标。若只想核对同分阵容，可在「计分参数」选择「等于目标分也算过关」。

## 本地运行

在项目目录执行以下命令，需要 Python 3。

```sh
python -m http.server 8765 --bind 127.0.0.1
```

打开 [本地网页](http://127.0.0.1:8765/)。也可以直接用浏览器打开 `index.html`，再手动选择 `data/data.min.json` 加载图鉴。直接打开文件时，单次搜索限时 2 秒。

## 数据来源

项目图鉴由 L 版图鉴与白菜菊花的公开数据合并而成，涵盖菜谱、厨师、厨具、遗玉和技能。 [L 版图鉴](https://foodgame.github.io/) · [白菜菊花图鉴](https://h5.baochaojianghu.com/)

通过校验码导入时，浏览器向游戏的档案接口请求当前配置。点单、档案和求解均在访问者的浏览器中处理。
